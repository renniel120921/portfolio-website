Case Study · PWA Discovery Shelf

Likha Apps

Project Overview

Likha Apps is an open-web progressive web app discovery shelf and directory platform designed to list, search, and launch web applications without native app store friction, review commissions, or packaging complexity.

Verified Architecture Flow

Next.js 16 / TypeScript UI
Firebase Auth
Cloud Firestore
Vercel Edge CDN

Problem Addressed

Traditional mobile app distribution demands rigid store review processes, annual developer subscriptions, and high platform cut rates. Web developers needed a lightweight, accessible directory where users can discover and install PWAs instantly.

Role & Technical Approach

As Full-Stack Developer, architected the application on Next.js 16 with React 19, implemented TypeScript strict typing, styled responsive layouts with Tailwind CSS v4, and integrated Firebase Authentication with Firestore real-time queries.

Key Engineered Features

  • Debounced Real-time Search: Sub-100ms keyword filtering across published web applications.
  • Category Filtering & Sorting: Instant browsing by utility, productivity, tools, and entertainment tags.
  • Direct PWA Launching: Launch applications in standalone browser windows with install prompts.
  • App Submission Pipeline: Verified creator submission flow with metadata validation.

Verified Outcome

Deployed and live on Vercel at likha-app-web.vercel.app. The codebase is maintained as an open-source project on GitHub under renniel120921/PWA-Storeapp.

Case Study · Personal Finance

Tipid App

Project Overview

Tipid App is a personal finance and daily expense tracking web application tailored for Filipino daily spending realities, equipped with offline functionality, allowance calculators, grocery tracking, and visual breakdown charts.

Verified Architecture Flow

HTML / CSS / JS UI
Firebase Authentication
Cloud Firestore
Service Worker Offline Sync

Problem Addressed

Most commercial finance apps are bloated, require constant internet access, and are built around foreign banking conventions. Filipino students and workers needed a lightweight, zero-cost tracker that functions reliably during transit and spotty connectivity.

Role & Technical Approach

Built the complete client-side architecture using modular ES6+ JavaScript, custom CSS3 responsive layouts, Firebase Authentication for private user vaults, and Service Worker caching for seamless offline usability.

Key Engineered Features

  • Offline Usability: Service Worker caches assets and records transactions even without internet access.
  • Allowance & Budget Calculator: Daily Filipino budget allocation with automated savings targets.
  • Debt & Utang Tracker: Clear ledger tracking receivables and payables for everyday transactions.
  • Visual Expense Analytics: Clean client-side chart breakdown of monthly expense categories.

Verified Outcome

Deployed and live on Vercel at tipid-tracker-nu.vercel.app. Code is publicly available on GitHub at renniel120921/Expenses-Tracker.
